# Retrieval-Augmented Generation (RAG)

A Retrieval-Augmented Generation system currently under development.

## Planned Features
- PDF Document Processing
- Semantic Search
- Vector Database Storage
- Retrieval Pipeline
- Conversation Memory
- Source Citation Support
- Local LLM Integration

## Technologies
- Python
- FAISS
- LangChain
- Sentence Transformers
- Ollama
- Streamlit

## Status
Work in progress. This project is being developed as part of my exploration of Artificial Intelligence and Retrieval-Augmented Generation systems.
